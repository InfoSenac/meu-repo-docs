# Base de Conhecimento Operacional de TI

Bem-vindo à documentação técnica oficial de infraestrutura e suporte.

Este portal reúne os **Procedimentos Operacionais Padrão (POPs)**, manuais de contingência, arquiteturas de armazenamento e guias de resolução de problemas desenvolvidos ao longo do curso Técnico em Informática.

## Índice de Módulos Técnicos

* **[POP-001: Clonagem Direta de Disco](modulos/pop-001-disk-to-disk.md):** Substituição e migração de unidades de armazenamento (HDD para SSD).
* **[POP-002: Backup e Criação de Imagens](modulos/pop-002-image-backup.md):** Criação e validação de imagens de sistema para recuperação a desastres.
* **[POP-003: Restauração Massiva via Rede](modulos/pop-003-lite-server.md):** Distribuição automatizada de SO com Clonezilla Lite Server e PXE.
* **[Matriz de Troubleshooting](modulos/troubleshooting.md):** Diagnóstico de falhas de partição, rede e integridade.
